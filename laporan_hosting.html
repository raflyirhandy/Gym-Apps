5. Penjelasan Aplikasi

A. Latar Belakang & Tujuan:
Pengelolaan gym konvensional sering mengalami kendala pada pencatatan keanggotaan, pembagian jadwal kelas yang bertabrakan, ketidaktransparanan bukti pembayaran, serta minimnya privasi dan keamanan data anggota. Aplikasi MachoGym dibangun untuk memodernisasi tata kelola pusat kebugaran berbasis web yang aman, terintegrasi, dan mudah digunakan dengan pemisahan peran yang tegas (Admin, Trainer, dan Member).

B. Fitur Utama Aplikasi:

  1. Autentikasi & Otorisasi: Registrasi mandiri, login multi-role, logout aman, serta proteksi route pada sisi frontend dan middleware backend.
  2. Pengelolaan Data (CRUD Berbasis Database):
    • Admin: Tambah, lihat, ubah status, dan hapus data Member, Trainer, dan Kelas latihan.
    • Trainer: Menyusun dan memperbarui program latihan fisik spesifik per member.
    • Member: Booking kelas latihan, submit data progres fisik harian, dan upload bukti pembayaran.
  3. Laporan & Monitoring:
    • Dashboard ringkasan statistik (total member aktif, trainer, kelas).
    • Tabel rekapitulasi pembayaran dan verifikasi tagihan membership.
    • Visualisasi grafik progres kebugaran member (berat badan, durasi latihan, beban).
  4. Fitur Interaktif: Konsultasi real-time antara member dan trainer binaannya.

D. Penerapan Aspek Keamanan (Secure Coding):

Aspek Keamanan Implementasi pada MachoGym Tujuan & Alasan
Password Hashing Menggunakan algoritma bcrypt dengan salt rounds standar industri saat registrasi dan validasi login. Mencegah kebocoran kata sandi dalam bentuk plaintext jika database terekspos.
Pencegahan SQLi Menggunakan Prepared Statements dan Parameterized Queries via Sequelize ORM / PDO. Memisahkan query instruksi SQL dengan data input user, sehingga karakter berbahaya dinetralisir.
Pencegahan XSS Sanitasi input, encoding karakter HTML pada rendering React (auto-escaped JSX), dan validasi tipe data di backend. Mencegah injeksi skrip JavaScript jahat yang dapat mencuri sesi/token pengguna.
Manajemen Sesi / JWT Token JWT disimpan dalam cookie bertanda flag HttpOnly dan Secure serta verifikasi signature token. Melindungi token dari pembacaan oleh script via DOM (XSS) dan memastikan enkripsi saat transmisi.
Kontrol Akses (RBAC) Middleware proteksi peran (Admin, Trainer, Member) di setiap endpoint API dan navigasi frontend. Mencegah kerentanan IDOR dan akses menu sensitif oleh pengguna yang tidak berhak.
Environment Secrets Kredensial database, JWT Secret, port, dan API key disimpan di .env dan di-exclude dari Git via .gitignore. Mencegah kebocoran rahasia sistem pada public repository GitHub.
HTTPS & TLS Sertifikat SSL/TLS terpasang valid pada domain machogym.my.id dengan redirect otomatis dari HTTP. Menjamin kerahasiaan transmisi data (anti Man-in-the-Middle / sniffing).

8. Hasil Self-Testing Keamanan (Minimal 5 Skenario)

Pengujian mandiri dilakukan secara manual menggunakan Browser DevTools, Curl, dan simulasi payload serangan:

No Skenario Uji Metode / Cara Pengujian Hasil Awal Tindakan Perbaikan & Status Akhir
1 SQL Injection pada Form Login Menginput payload ' OR '1'='1' -- pada field email login dan password. LOLOS Input diproses menggunakan ORM parameterized query; sistem mengembalikan "Email atau password salah" tanpa eksekusi query liar.
2 Cross-Site Scripting (XSS) pada Form Input Memasukkan script <script>alert('XSS')</script> pada nama member dan catatan progress. LOLOS Karakter HTML di-escape secara otomatis oleh template frontend React JSX; script hanya tampil sebagai teks murni tanpa dieksekusi.
3 IDOR / Role Access Control (User biasa buka Admin) Login sebagai akun member, kemudian mencoba mengakses URL /admin/members dan endpoint GET /api/admin/classes. LOLOS Frontend me-redirect ke dashboard member; backend mengembalikan HTTP 403 Forbidden melalui middleware otorisasi.
4 Kebocoran Secret di Git Repository Pemeriksaan git log dan pencarian file kredensial database/API key pada commit publik. LOLOS File .env telah masuk ke .gitignore; repository hanya memuat file .env.example tanpa password nyata.
5 Pemeriksaan Enkripsi HTTPS & SSL/TLS Mengakses domain https://machogym.my.id/ melalui browser dan menguji koneksi HTTP port 80. LOLOS Koneksi memiliki sertifikat SSL/TLS valid (ikon gembok terkunci), akses via HTTP otomatis dialihkan (redirect 301) ke HTTPS.

10. Kendala dan Rencana Perbaikan
Kendala yang Dihadapi Solusi & Rencana Perbaikan
1. Konfigurasi CORS pada Domain Kustom:
Saat pertama kali deploy ke domain machogym.my.id, browser sempat menolak request API karena origin domain belum terdaftar di whitelist CORS backend. 		Solusi:
Menambahkan origin https://machogym.my.id ke dalam array allowedOrigins di konfigurasi middleware Express/CORS, serta memastikan credentials: true.
2. Sinkronisasi Sesi Chat Real-time:
Koneksi WebSocket pada lingkungan hosting memerlukan konfigurasi proxy port dan header upgrade (WebSocket Handshake). 		Solusi:
Menyesuaikan konfigurasi reverse proxy hosting untuk mengizinkan protokol Upgrade dan Connection: Upgrade untuk Socket.io.
